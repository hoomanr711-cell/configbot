# ربات کانفیگ هومان 😄

این ربات خودش هر ۳ ساعت یه بار از کانال‌های عمومی تلگرام **کانفیگ V2Ray** (برای B2Ray) و **پروکسی تلگرام** جمع می‌کنه، سرورهای مرده رو دور می‌ریزه و نتیجه رو توی چند تا فایل می‌ذاره.
روی سرورهای رایگان گیتهاب اجرا می‌شه؛ نه گوشی تو لازمه، نه لپتاپ، نه VPS.

## راه‌اندازی (فقط یه بار، حدود ۱۰ دقیقه، با لپتاپ راحت‌تره)

1. تو **github.com** یه اکانت بساز (Sign up). اگه سایت باز نشد، با همون اتصالی که الان داری بازش کن.
2. بالا سمت راست روی **+** بزن، بعد **New repository**. یه اسم بذار، مثلاً `configbot`، حتماً **Public** رو انتخاب کن، بعد **Create repository**.
3. زیپ رو از حالت فشرده دربیار. تو صفحه‌ی ریپو روی **uploading an existing file** بزن، همه‌ی فایل‌ها و پوشه‌ی **.github** رو بکش و رها کن، آخرش **Commit changes**.
   - اگه پوشه‌ی `.github` دیده نشد (تو مک و لینوکس مخفیه): **Add file ← Create new file** رو بزن، تو کادر اسم بنویس `.github/workflows/collect.yml` (با تایپ `/` پوشه‌ها خودکار ساخته می‌شن)، محتوای فایل `collect.yml` رو کپی-پیست کن و **Commit**.
4. تب **Actions** رو باز کن. اگه دکمه‌ی فعال‌سازی اومد بزنش. از لیست سمت چپ **Collect configs** رو انتخاب کن، بعد **Run workflow** و دوباره **Run workflow**.
5. ۱ تا ۲ دقیقه صبر کن تا تیک سبز بیاد. حالا توی ریپو فایل‌های `sub.txt` و `configs.txt` و `proxies.txt` و `PROXIES.md` ساخته شدن.

از این به بعد خودش هر ۳ ساعت آپدیت می‌کنه.

## استفاده

### کانفیگ V2Ray برای B2Ray

لینک ساب (Subscription) تو اینه، به جای `USERNAME` اسم کاربری گیتهابت رو بذار (و اگه اسم ریپو رو چیز دیگه‌ای گذاشتی، `configbot` رو هم عوض کن):

```
https://raw.githubusercontent.com/USERNAME/configbot/main/sub.txt
```

تو B2Ray بخش **Subscription** (اشتراک) رو باز کن، این لینک رو اضافه کن و آپدیت بزن. هر وقت کانفیگ‌ها مردن دوباره آپدیت بزن.

اگه ساب جواب نداد: فایل `configs.txt` رو تو گیتهاب باز کن، همه‌ی خط‌ها رو کپی کن و از کلیپ‌بورد تو B2Ray وارد کن.

### پروکسی تلگرام

فایل `PROXIES.md` رو تو گیتهاب باز کن و روی یه لینک بزن؛ تلگرام می‌پرسه می‌خوای وصل بشی (Connect Proxy). اگه یکی کار نکرد، بعدی رو امتحان کن.

## نکته‌های مهم

- **قطع کامل بین‌الملل = هیچ‌کدوم کار نمی‌کنه.** پس تا نت بین‌الملل هست آپدیت بزن و کانفیگ‌ها رو تو B2Ray نگه دار.
- «سالم» یعنی پورت سرور باز بوده، نه اینکه سرعتش خوبه. کانفیگ‌های رایگان زود می‌میرن.
- سرورها مال آدم‌های ناشناسه. برای بانک و ایمیل اصلی ازشون استفاده نکن.
- کانال جدید می‌خوای؟ فایل `channels.txt` رو تو گیتهاب باز کن، آیکن مداد رو بزن، اسم کانال رو (بدون @) تو یه خط جدید بنویس و Commit کن.
- اگه بعد از چند هفته آپدیت‌ها ایستاد (گیتهاب گاهی اجرای خودکار رو خاموش می‌کنه)، دوباره **Run workflow** رو بزن.
